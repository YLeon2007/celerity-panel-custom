# Preliminary offline node-side intent journal (dormant)

This is a **local contract experiment only**. It is not installed on a node, invoked by workers, reachable through SSH, or an enforcement point. It cannot prove process-tree quiescence, authorize a remote command, or make the current production transport safe. Production topology/L2TP dispatch remains fail-closed independently of this module. Do not interpret `"blocked"` as permission to run anything.

`journal.py` exposes only `initialize(private_absolute_directory, generation)` and `record_intent(private_absolute_directory, generation, command_id, sha256_hex_digest)`. The caller must create a private owner-only directory per node, on a local filesystem with working SQLite WAL and fsync semantics; do not use network filesystems. Initialization creates a new database only when its path is absent. No epoch rotation or reset exists. One first attempt in the active generation is recorded transactionally with `blocked=1`; after commit and directory fsync the call returns `"blocked"`. An exact duplicate also returns `"blocked"`; changed digest, different generation, second command, unsafe file or invalid state reject. There is no command text, execution, clear, dispatch, or proof API. The SQLite file and its WAL/SHM are private. The database is not a tamper-evident ledger: deletion, malicious same-UID modification, storage dishonesty, and independent command routes are outside this contract. Do not use it as evidence that commands are fenced in production.

Offline tests: `python3 -m unittest discover -s src/modules/relay-l2tp/node-artifacts/fence -p 'test_*.py' -v`.
