# C³ CELERITY 1.6.42 — цепочки релеев

## Что изменилось

- В Rebuild можно построить цепочку **портал → релей → ещё один или несколько релеев → бридж**. У каждого портала может быть свой конечный бридж, даже если часть пути общая.
- Выберите бридж в настройках связи портала и откройте **«Предпросмотр»**. Панель покажет путь, изменения и запланированные перезапуски при создании каналов. Если бридж недостижим или путь неоднозначен, применить его нельзя. Чтобы вернуть порталу общий маршрут релея, снимите выбор выхода и снова пройдите предпросмотр и применение.
- После перезагрузки релея панель повторно проверяет его состояние и снова читает существующие L2TP-учётки. Переустанавливать L2TP или создавать учётки заново не нужно.

## После обновления панели

1. Для каждого узла в цепочке один раз примените текущую конфигурацию обычной кнопкой **«Применить» (Apply)**. Это обновит основной профиль Xray (MAIN). Если шаг ещё не выполнен, предпросмотр цепочки подскажет, на каких узлах он нужен. Синхронизация пользователей этот шаг не заменяет.
2. Если для выбранного выхода подходят уже применённые общие каналы, обычный Apply работает и без флага. Если конфигурации нужны новые выделенные каналы между релеями, их применение по умолчанию отключено. Для него нужно отдельно задать `C3_REBUILD_CHAIN_APPLY=1` в окружении панели. На рабочей панели включайте флаг только после принятия решения о выкладке.
3. Сначала проверьте путь и изменения в предпросмотре, затем подтвердите Apply. Если панель сообщает, что итог операции не подтверждён, не повторяйте её автоматически: сначала нужно сверить состояние.
