# C³ CELERITY 1.6.37 — Длительные подключения Xray

- Пока Xray держит соединение открытым, оно остаётся в списке и счётчике при каждом свежем снимке. Снимок живёт до 60 секунд от времени обновления. Колонка «Последнее подключение» показывает время открытия соединения, а не время последней активности.
- cc-agent 1.6.1 использует служебные соединения Rebuild только для проверки поддержки учёта: их имена и IP не возвращаются. Пустой подтверждённый список показывает «Нет активных подключений». Если свежий ответ агента 1.6.1+ не подтверждает учёт, карта показывает «Нет подключений или учёт на ноде не включён»; при сбое запроса — «Данные о подключениях недоступны». Доступ к IP по-прежнему только из админской сессии.
- Порядок выкладки: панель 1.6.37 → cc-agent 1.6.1 на порталы. Конфиги Xray не меняются, Apply не нужен.
