# C³ CELERITY 1.6.36 — Счётчик клиентов на карте

Новая карта опрашивает топологию каждые 10 секунд только на видимой вкладке. Открытый список подключений обновляется каждые 15 секунд и сразу передаёт счётчикам число уникальных пользователей. Опрос не закрывает окно и сохраняет положение и масштаб графа.

Обновляется только панель. cc-agent остаётся 1.6.0, конфиги Xray не меняются, Apply не нужен. Доступ к списку по-прежнему только из админской сессии, не по API-ключу.
