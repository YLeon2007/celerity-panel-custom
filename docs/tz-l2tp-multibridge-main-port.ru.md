## 1. Состав переносимого функционала

### 1.1. Модуль relay-l2tp (новый, 192 файла / ~51k строк)
- L2TP/IPsec-релеи: install/uninstall/preflight, аккаунты (create/delete/fan-out), chap/IPsec secrets, tproxy-интеграция с Xray.
- Каскадная топология v1: draft → validate → pin → operation (queue/worker/executor) → runner на нодах с `xray run -test` и receipt.
- Multi-bridge: одна линейная main-цепочка + дополнительные geo-leaf бриджи с `geoRouting` (domains/geoip). Refs `bridge`, `bridge-2`, …
- Route-группы (priority-failover) и per-path socks-ingress на релеях для L2TP-трафика.
- UI: страница L2TP (релеи, аккаунты, копируемый IP-чип), карта топологии.

- На бриджах нет IPv6 — клиентские AAAA-запросы требуют отдельного решения (вне scope).
