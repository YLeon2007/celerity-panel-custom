# C³ CELERITY 1.6.38 — Свой выход портала

- В новой карте откройте связь «портал → релей» и выберите бридж в поле «Выход этого портала». Сохранение создаёт черновик; проверьте изменения в Preview и подтвердите Apply. «Общий выход релея (по умолчанию)» сохраняет прежнее поведение.
- Выбор закреплён за нодой. При нескольких активных каналах к одному выходу используется наименьший числовой приоритет. Удаление предпочтительного канала через Preview → Apply переключает маршрут на оставшийся; Preview показывает смену канала. Последний активный канал нельзя удалить или деактивировать, пока на выход ссылается черновой или применённый выбор портала (`409 REBUILD_EXIT_IN_USE`). Сначала выберите и примените другой или общий выход.
- При включённой галочке «Ру-трафик через шлюз релея» действуют правила геомаршрутизации релея. Выбор geo-бриджа с выключенной галочкой отправляет через него весь трафик этого портала, который дошёл до релея.
- Только Rebuild и один релей. Нет автоматического переключения по состоянию туннеля. Настройки Classic, подписки, cc-agent и общий маршрут PPP/L2TP не меняются. Отдельный выход L2TP в выпуск не входит.
