# nodeSetup: локальный комплект cc-agent 1.5.1 (MAIN)

В **отдельном экземпляре панели с применённым патчем** дайте процессу панели доступ только на чтение к каталогу с принятыми `cc-agent-linux-amd64`, `cc-agent-linux-arm64`, `SHA256SUMS`. Укажите абсолютный путь к нему в окружении процесса, например `CC_AGENT_OFFLINE_KIT_DIR=/mnt/main/cc-agent-1.5.1`. Для контейнера это путь **внутри контейнера**. Затем используйте обычную настройку Xray-ноды с агентом. Выбор действует на все установки cc-agent этим процессом, а не на отдельное поле карточки ноды. Настройки на самой ноде не нужны.

Если переменная не задана, остаётся штатный загрузчик. Пустое значение — ошибка, а не отключение режима. Закреплён именно манифест MAIN (`b229552a95d647c950cec7000a553cda15558f816f1742c3ada215c7aaf76961`). Проверяются оба бинарника до настройки; при неизвестной архитектуре или ошибке проверки агент не заменяется. При потере подтверждения после передачи проверьте SHA-256 установленного файла: замена уже могла состояться. Автоматического повтора или перехода на GitHub в этом режиме нет.

Офлайн-режим заменяет **только получение бинарника агента**. Настройка Xray, конфигурация и запуск службы не меняются. Это не офлайн-режим всей Auto Setup и не обновление ранее переданной сборки панели.
