# C³ CELERITY v1.6.35

На новой карте наведите курсор на счётчик клиентов в «Цепочках», «Графе» или инспекторе ноды, чтобы увидеть IP, недавно замеченные Xray. Список доступен только в сессии администратора панели, не через API-ключ или MCP. Данные подключений хранятся только в памяти панели, не дольше 60 секунд. Функция не записывает IP клиентов в логи, аудит, Redis или MongoDB.

## Порядок выкладки

1. Обновите панель до 1.6.35. До обновления агента у онлайн-портала с 1.5.1 подсказка попросит агент 1.6.0; если статус ноды `unknown`, данные будут отмечены как недоступные.
2. Обновите cc-agent до 1.6.0 на порталах и на standalone Xray-нодах, где нужна эта функция.
3. Для связей Rebuild откройте штатный Preview: для включения статистики у портала меняется только `policy`, без `protectedChanged`. Подтвердите Apply только после проверки плана. Apply записывает `policy.levels."0".statsUserOnline: true` в MAIN и **перезапускает Xray на каждом затронутом портале**. Профили релеев и мостов и клиентские подписки для этой функции не меняются.

Для standalone Xray-ноды **без связей и без управления конфигом через топологию** вместо Apply после обновления агента выполните обычный Sync этой ноды (`POST /api/nodes/:id/sync`). Для обновления MAIN нужен настроенный SSH; при успешной записи профиля Sync тоже перезапускает Xray. Сообщение о запуске Sync не подтверждает окончание: дождитесь завершения и проверьте `statsUserOnline` в MAIN.

Дашборд считает пользователей по действительному снимку `/online-ips`, а при его отсутствии использует подсчёт 1.6.34. На проверенных Xray 26.3.27 и 26.11.9 список учитывает только открытые соединения и не учитывает подключения с `127.0.0.1`. Пустой список сам по себе не подтверждает, что `statsUserOnline` включён.

Положите необязательные MMDB-базы DB-IP Lite в `/app/data/geoip/city.mmdb` и `/app/data/geoip/asn.mmdb` или укажите пути внутри контейнера панели в `GEOIP_CITY_DB` и `GEOIP_ASN_DB`. Для обновления заменяйте файлы атомарно — перезапуск не нужен. Если одного из файлов нет, соответствующие поля останутся пустыми. Если база не содержит провайдера, показывается организация ASN. Баз в образе нет.
